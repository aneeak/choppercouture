# E-Mail-Vorlagen

Nicht Teil der Website — wird beim Build ignoriert und landet nicht im
Deployment. Nur Vorlagen zum Kopieren.

## vorab-info.html

Sammelmail an alle Vorverkaufs-Käufer, gedacht etwa eine Woche vor dem Event.

**Betreff:** Deine Tickets für die Dental Jewelry Expo — 24.10., Bunker West

**Versand:**
1. Datei im Browser öffnen, alles markieren und kopieren.
2. In Gmail einfügen.
3. Empfänger ins **BCC**-Feld, nicht ins An-Feld. Sonst sieht jeder Käufer
   die Adressen aller anderen — das wäre ein Datenschutzverstoß.
   Ins An-Feld die eigene Adresse.

Die Käufer-Adressen kommen aus den PayPal-Zahlungseingängen.
